本政策说明 GLOBULAR CLUSTER TECHNOLOGY SOFTWARE LIMITED（“我们”）如何在本网站 globularcluster.ca（“本网站”）以及用于下单和付款的支付网站 [pay.globularcluster.ca](https://pay.globularcluster.ca)（“支付网站”）上处理你的个人信息。

## 我们收集的信息

**本网站**

- 联系表单：你提交的姓名、邮箱、电话（选填）和留言内容。表单由 Formspree 处理并通过邮件转发给我们。
- 本网站不使用任何统计或追踪工具，也不设置 Cookie。

**支付网站**

- 账户信息：邮箱、（注册时的）姓名与密码哈希。
- 订单信息：购买的服务、金额、币种、付款时间与状态；结账时填写的账单地址（用于计税）。
- 技术信息：登录会话和语言偏好所需的 Cookie。

卡号、微信支付 / 支付宝账户等支付信息**由 Stripe 直接处理，我们不接触也不保存**。

## 用途

- 回复你的咨询；
- 交付你购买的服务、处理付款、退款与订阅管理；
- 发送订单确认、续费提醒等服务相关邮件；
- 依法计算和申报税款、防范欺诈。

我们不出售你的个人信息。

## 共享

仅在运营网站和提供服务所必需时与以下各方共享：

- GitHub Pages（本网站托管）、Formspree（联系表单）。你访问本网站或提交表单时，这些服务商在提供服务的过程中可能获取你的 IP 地址、浏览器信息等技术数据。
- Stripe（支付处理）、Cloudflare（支付网站托管）、邮件发送服务商。
- 法律要求时向主管机关提供。

## 保留与你的权利

订单记录按税务法规要求保留；联系表单留言仅在处理你的咨询所需期间保留；其他信息在你注销账户后删除。你可随时发邮件至 <support@globularcluster.ca> 查阅、更正或删除你的个人信息。

## 政策变更

我们可能不时更新本政策，以上方的“最后更新”日期为准。
